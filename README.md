# MOONSTAR

**Junior Astronaut Mission Trainer**

MOONSTAR is a 3D lunar survival simulator where players take control of a Moon base and make decisions to keep their crew alive.

Created for the **NASA Space Apps Challenge 2026**, this project is designed to help children learn about space exploration, science and engineering through gameplay.

## Features

- Interactive 3D lunar base.
- Resource management: energy, water, oxygen and food.
- Different missions, difficulties and crew sizes.
- Random events that affect the mission.
- Real NASA data integration (DONKI, OSDR and RadLab).
- Earth–Moon communication delay simulation.
- Interactive Space Academy with educational lessons.
- Mission reports and progress saving.
- Spanish and English support.

## Built With

- React + TypeScript
- Three.js
- Vite
- Node.js + Express


## NASA Data

MOONSTAR uses scientific resources from:

- [NASA DONKI](https://ccmc.gsfc.nasa.gov/tools/DONKI/)
- [NASA OSDR](https://osdr.nasa.gov/)
- [NASA RadLab](https://visualization.osdr.nasa.gov/radlab/gui/data-api/)

Some mission values are simulated for gameplay. Real NASA data and historical fallback data are identified separately.
